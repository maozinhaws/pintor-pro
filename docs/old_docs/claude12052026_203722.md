## Tarefa 2 — Banco de Dados SQLite

**Branch atual:** `feature/storage-sqlite-dexie-offline`

### Contexto
O app atualmente salva tudo em `localStorage` como JSON. Problema: limite de 5–10MB esgota rápido com fotos em Base64.

### O que implementar
- [ ] Instalar e configurar `@capacitor-community/sqlite` (plugin Capacitor)
- [ ] Criar schema do banco:
  - `clientes` (id, nome, telefone, endereco, created_at)
  - `orcamentos` (id, cliente_id, titulo, status, total, created_at, updated_at)
  - `itens` (id, orcamento_id, nome, alt, comp, servicos, preco, por_metro, obs)
  - `fotos` (id, item_id, filename, data_url, annotated, created_at)
- [ ] Criar camada de acesso (`src/db.ts`) com funções CRUD
- [ ] Migração dos dados existentes do `localStorage` para SQLite
- [ ] Testar no Android (SQLite nativo via Capacitor)

### Decisões a tomar
- Fotos: manter Base64 no SQLite ou salvar em arquivo local via `@capacitor/filesystem`?
  - Recomendação: salvar em arquivo, guardar apenas o path no banco
